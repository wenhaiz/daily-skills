# 产品事实库

这里保存 {{PROJECT_NAME}} 值得长期复用的稳定知识。代码和真实配置仍然是最终事实源。

## 维护原则

- 只记录跨文件、跨状态或后续工作需要反复理解的知识。
- 不能从代码确认的内容标记为待确认。
- 每个 domain 记录 `verified_commit` 和具体的 `watch_paths`。
- 开发进度写进 Plan，不写进事实库。

## 目录

- `10-domains/`：按业务域或系统域记录当前事实。
- `40-intent/`：长期原则、能力边界和重要取舍。
- `80-process/`：维护与核验流程。
- `90-templates/`：项目自己的事实文档模板。
