# Markdown 实时预览

```bash
python3 <skill-directory>/scripts/serve.py --markdown /absolute/path/post.md
```

网页顶部的内容来源入口可切换「网页编辑」与「Markdown 文件」，输入本地 `.md` 或 `.markdown` 文件完整路径即可连接，无需重启服务。`--markdown` 仅指定打开网页时的初始文件；切换文件不会更改服务的默认文件，也不会修改 Markdown。不同网页可分别预览不同文件。

在编辑器中修改并保存文件，网页约每秒检查一次变化，自动更新页面与图片。网页不写入或改写 Markdown；内容、页面顺序、图片说明等都由文件决定。样式设置、当前页标题高亮范围和图片宽度仍可在网页调整，图片宽度按源图片路径和画布尺寸独立保存，文件实时同步或图片内容变化时保留调整；点击「重置」恢复 Markdown 中的宽度。两套尺寸样式独立保存到浏览器，并按文件路径隔离。原有网页编辑与 JSON 模式仍可使用。

标题高亮范围按文件、页面标题保存，正文修改和不同标题页面排序后仍保留；同名标题使用内容摘要区分，调序后不会互换设置；修改同名页面正文后，需要重新设置该页高亮。修改标题后使用该标题对应的设置，点击「重置高亮范围」恢复 Markdown 中的 `highlight` 设置。两个尺寸共用指定的高亮文字，仍不支持跨行匹配。

## 内容规则

- 第一页为封面，`# 标题` 为封面标题，其余文字为副标题。
- `## 标题` 自动开始正文页；也可用独立一行的 `---` 明确分页。续页可不写标题。
- 标题和副标题中的 `<br>` 可用于换行。
- 正文保留段落和简单 Markdown 列表；不支持完整 Markdown 排版。
- 标准图片：`![图片说明](./images/example.png)`。支持本地 PNG、JPEG、WebP，不读取网络图片。
- 图片宽度：`![图片说明](./images/example.png){width=40}`，表示占正文区域宽度的 40%，允许 20–100，默认 100。
- 支持 Obsidian 图片 `![[example.png]]`，可写 `![[example.png|40%]]` 调整宽度。优先按相对路径读取，找不到时在 Obsidian vault 内精确匹配文件名；同名文件需要明确路径。
- 每页可写 `<!-- highlight:标题中的几个字 -->` 指定下划线，留空自动。
- 页末 `### 参考资料` 或 `### 底部说明` 后的文字作为底部说明；兼容 `> 参考资料：` 开始的引用块。

```markdown
# 吉他练习的 6 个方向

每天练琴，除了爬格子，还能练什么？

## 歌曲练习
<!-- highlight:歌曲 -->

我们可以把练习的歌曲分成三类：

- 简单歌曲：轻松就能弹下来
- 「差不多」歌曲：针对细节练习
- 理想歌曲：暂时超出当前水平的曲目

![练习时间分布](./images/practice.png){width=40}

### 参考资料
资料名称与来源

---

这是没有标题的续页。
```

保存时内容暂时为空、图片找不到或解析失败，网页显示错误并保留上一次正常预览；修复并保存后自动恢复。内容溢出时仍需在 Markdown 中减少文字、调整图片宽度或用 `---` 拆页。

服务接口 `/source.json?path=<完整路径>` 返回所选文件的页面、绝对路径和版本标识。省略 `path` 时使用启动参数中的默认文件；未配置默认文件时返回 204。传入 `revision` 且内容未变化时同样返回 204。路径或内容错误返回可读的 422 JSON。服务缓存最近 4 个动态选择的文件及其图片编码，各文件读取有独立锁；切换仅影响发起请求的网页。
