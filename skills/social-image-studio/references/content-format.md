# 内容格式

```json
{
  "version": 1,
  "style": { "accent": "#319FFF", "bodySize": 42, "lineHeight": 1.55, "marginX": 90, "marginY": 100, "letterSpacing": 2.75 },
  "pages": [
    {
      "type": "cover",
      "title": "6 个方向\n帮你安排练琴",
      "subtitle": "",
      "body": "",
      "note": ""
    },
    {
      "type": "article",
      "title": "技术",
      "subtitle": "Technique",
      "body": "第一段正文。\n\n第二段正文。",
      "note": ""
    }
  ]
}
```

- `version`：固定为 1。
- `style`：整组页面共用。`aspectRatio` 可选 `3:4`（默认，1242 × 1656 px）或 `9:16`（历史字段值，对应自定义尺寸 1280 × 2124 px，实际不为 9:16）。切换尺寸时恢复该尺寸对应的样式配置，旧草稿默认 3:4。`accent` 为六位十六进制颜色，`bodySize` 为 28–48 的整数，默认 42；`lineHeight` 为 1.2–2.2 的行距倍数，默认 1.55；`marginX` 为两边各自的留白宽度，60–240 px 的整数，默认 90，封面在此基础上两侧各增加 60 px；`marginY` 为上下各自的留白高度，60–360 px 的整数，默认 100；`letterSpacing` 为正文字间距，0–6 px，默认 2.75。正文从上边距开始，封面在上下留白之间居中；底部说明也保持在留白以内。未包含这些字段的旧草稿使用对应默认值。
- `pages`：1–50 页，数组顺序就是导出顺序。
- `type`：`cover` 或 `article`。
- `title`：标题，支持换行。正文标题为空或全为空白时，不显示下划线，也不预留标题区域，正文从上边距开始。
- `subtitle`：可选封面副标题，正文页忽略此字段，支持多行输入及自动换行。封面副标题使用 36 px 灰色苹方，随标题组成的内容块居中。
- `body`：正文。空行区分段落，普通换行保留；支持简单 Markdown 列表：独立一行以 `- `、`* `、`+ ` 开头显示为圆点列表，以 `1. ` 或 `1) ` 等开头显示为编号列表，长条目换行与条目文字对齐。暂不支持嵌套列表，前导空格不会增加层级；其他 Markdown 语法按普通文字显示。封面不显示正文。
- 旧内容中的 `emoji` 字段仍可读取，但不再显示；需要图标时直接写在标题中。
- `highlight`：可选下划线文字，只匹配标题中第一次出现的内容，必须完整位于同一渲染行。留空使用自动下划线；未匹配或跨行时提示且不画下划线。正文标题为空时忽略此字段。
- `note`：可选底部说明 / 参考资料，兼容原有署名。支持多行和自动换行，使用 20 px 灰色宋体、40 px 行距，在下边距之上靠左显示。按实际高度预留正文空间，正文与底部说明之间保留 44 px；留空或全为空白时不占空间，内容放不下时提示溢出并阻止导出。

缺省文字字段按空字符串处理；每个字段最多 10000 字符。导入文件最大 20 MB。编辑器保存的 JSON 可直接重新导入或通过 `--content` 加载。

正文支持本地图片：`images` 为可选数组，每页最多 8 张。每项包含 `src`（PNG/JPEG/WebP 的 base64 data URL，最多 1500000 字符）和 `width`（占正文区域宽度的百分比，20–100 的整数，默认 100）、可选 `caption`（图片说明，最多 500 字符，默认空字符串）。说明在图片下方以 26 px 浅灰色苹方居中显示，过长按图片宽度换行，空值不占空间。在 `body` 中单独一行写 `[图片1]`、`[图片2]` 等标记，按数组顺序引用；图片居中并保持比例，使用 16 px 圆角和轻微阴影，封面不渲染图片。网页上传会缩小到最长边 1600 px、转为 JPEG，透明区域填白；图片数据随 JSON 保存，无需原始文件。标记引用不存在或损坏的图片时禁止导出。图片较多时浏览器草稿空间可能不足，请用「保存内容」备份。

全部页面 ZIP 文件名包含导出时间（北京时间，精确到秒），例如 `social-images-20261001-213012.zip`。

`styleProfiles` 为可选的两套样式配置对象，键为 `3:4` 和历史值 `9:16`（自定义竖版）。每项结构与 `style` 相同。`style` 表示当前正在使用的配置，保存时同步到对应配置；缺少配置的旧草稿以当前样式初始化两套。调整一套不会影响另一套，配置随浏览器草稿和 JSON 保存。

新建内容默认样式：3:4 使用 42 px 正文、1.55 倍行距、2.75 px 字间距、左右 90 px、上下 100 px；自定义竖版使用 44 px 正文、1.55 倍行距、2.75 px 字间距、左右 110 px、上下 140 px。两套强调色均为 `#319FFF`。

样式还支持三个字号：`coverTitleSize` 为封面标题（64–160 px，默认 112）、`coverSubtitleSize` 为封面副标题（20–60 px，默认 36）、`pageTitleSize` 为正文页标题（36–88 px，默认 56）。均为整数，随两套样式独立保存；标题行高和划线位置随字号调整，旧草稿使用默认值。
