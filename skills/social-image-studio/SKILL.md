# 社交图片工作台

用随附的网页编辑器完成内容到图片的流程。默认白底、苹方 Medium 标题、42 px 苹方正文、1.55 倍正文行距、2.75 px 正文字间距、左右各 90 px、上下各 100 px 留白、深灰正文、黑色标题和蓝色手绘下划线，封面与正文使用固定模板。预览和导出共用 Canvas 渲染，默认输出 1242 × 1656 px（3:4），可在全局样式中切换为 1280 × 2124 px（自定义竖版），两种尺寸各保存一套样式，切换时恢复对应配置；自定义竖版默认 44 px 正文、左右各 110 px、上下各 140 px，其余与 3:4 相同，不依赖图片生成服务或网络字体。

## Markdown 作为唯一内容源

用户已有 Markdown 或希望在编辑器中维护内容时，优先使用此模式：

```bash
python3 <skill-directory>/scripts/serve.py --markdown /absolute/path/post.md
```

网页只预览与导出，隐藏内容编辑和页面排序；保存 Markdown 后自动更新。`#` 为封面标题，`##` 自动开始正文页，`---` 可显式分页；支持标准图片与 Obsidian 图片。样式仍在网页调整，每个源文件分别保存两套尺寸配置，浏览器不保存内容副本。不要自动改写用户 Markdown。格式与限制见 [references/markdown-format.md](references/markdown-format.md)。解析失败时保留上一份预览，修复文件后自动恢复。

## 根据内容制作图片

- 根据用户内容整理封面和正文页，保留原意；仅在用户要求时改写或补充观点。
- 编辑器只显示当前页面支持的内容字段。续页可将正文标题留空，正文会从上边距直接开始，不显示下划线。
- 正文支持简单 Markdown 无序列表与编号列表，长条目换行与条目文字对齐。
- 正文支持本地图片，在正文光标位置用「插入图片」上传，独立一行的 `[图片1]` 标记控制位置。每张图可调宽度，保持比例，可添加图片下方的浅灰色小字说明；图片数据随草稿与 JSON 保存，导出前等待图片加载。
- 可在每页「下划线文字」字段指定标题中的文字，只支持同一渲染行内的首次匹配；留空沿用自动下划线。
- 封面标题通常 2–3 行，标题和副标题组成的内容块在页面中水平居中，块内各行保持左对齐。正文建议每页 3–5 段、约 250–400 字；以网页实际溢出提示为准，过长时拆页，不直接裁切文字。
- 在用户工作目录写入 UTF-8 JSON 草稿。结构见 [references/content-format.md](references/content-format.md)。不要覆盖 skill 内模板来存储用户内容。
- 在 skill 目录外运行时，将下面路径替换为实际 skill 的绝对路径：

```bash
python3 <skill-directory>/scripts/serve.py --content /absolute/path/social-pages.json
```

不带 `--content` 时，优先恢复当前浏览器草稿；没有草稿时显示练琴示例。带 `--content` 时按初始内容指纹隔离草稿，同一份初始内容再次打开会恢复已编辑的草稿。默认端口 8765，冲突时使用 `--port 8766` 等其他端口。

打开脚本输出的 localhost 地址，让用户逐页编辑与预览。支持新增/删除页、拖动页面列表排序（也可用 Alt + 上下箭头）、通过顶部「样式设置」全局悬浮菜单调整统一强调色、正文字号、行距、字间距与页面左右、上下边距、导入/保存 JSON、单页 PNG 和带导出时间的全部页面 ZIP（北京时间，精确到秒）。页面内容只在当前浏览器保存，不上传。导入会替换当前全部页面，网页会提示确认。

## 调整样式和验收

- 在 `assets/renderer.js` 调整图片排版、字体、边距和下划线；`assets/style.css` 仅控制编辑器界面。
- 根据选择的比例使用对应画布尺寸，预览与导出继续调用同一个 `StudioRenderer.draw`。
- 导出前检查全部页面：标题完整、正文没有溢出、底部说明与参考资料完整显示。网页会阻止溢出页面导出，并在批量导出时说明具体页码。
- 下载后核对 PNG 尺寸和 ZIP 页面顺序，至少查看封面与一张正文的真实导出图。
- 标题优先使用 macOS 的 PingFang SC Medium，正文使用 PingFang SC Regular；其他系统回退到本地黑体，底部说明使用本地宋体。不同机器可能略有差异；需要跨机器完全一致时，再随模板加入有授权的固定字体。
